# 우리동네 세계지도

법무부 출입국·외국인정책본부와 행정안전부 공개통계로 전국 시도·시군구별 등록외국인 분포를 탐색하는 모바일 우선 웹앱입니다.

> 이 서비스는 지역별 공개통계를 탐색하기 위한 도구입니다. 미등록·불법체류자 수나 범죄율을 나타내지 않으며, 국적만으로 개인 또는 지역의 위험을 판단하는 용도로 사용하지 않습니다.

## 배포

- Cloudflare Pages 목표 주소: `https://uridongne-map.pages.dev`
- Production branch: `main`
- Framework preset: `Next.js (Static HTML Export)`
- Build command: `npx next build`
- Build output directory: `out`

## 데이터

기본 스냅샷은 법무부 2026년 6월 등록외국인 지역별 현황과 행정안전부 2026년 6월 주민등록인구를 사용합니다.

- 전국 등록외국인: 1,636,922명
- 중국: 221,073명
- 한국계 중국인: 214,818명
- 중국 + 한국계 중국인: 435,891명
- 주민등록인구 + 등록외국인: 52,728,691명

대표 지표는 아래 식으로 계산합니다.

```text
(중국 + 한국계 중국인 등록외국인) ÷ (주민등록인구 + 등록외국인) × 100
```

전국 평균은 지역 인구 100명당 0.83명이며, 제주는 1.55명으로 17개 시도 중 1위입니다.

국적별 표와 체류자격별 표는 서로 다른 주변합이므로 `중국 국적 × D-2/E-9` 값을 임의 추정하지 않습니다.

## 로컬 실행

```bash
npm install
npm run dev
```

정적 빌드:

```bash
npm run build
```

빌드 결과는 `out/`에 생성됩니다.

## 네이버 지도

네이버 지도 키가 없어도 동일한 검색·지역 선택·결과 공유 기능을 갖춘 좌표 기반 데이터 지도로 동작합니다. 실제 네이버 지도를 사용하려면 배포 환경에 아래 공개 식별자를 설정하고 해당 도메인을 NAVER Cloud Platform의 Web 서비스 URL에 등록합니다.

```dotenv
NEXT_PUBLIC_NAVER_MAP_CLIENT_ID=
```

실제 키는 GitHub에 커밋하지 않습니다.

## 검증

```bash
npm test
```

- 17개 시도와 시군구 합계가 전국·시도 합계와 일치
- 중국 전체 = 중국 + 한국계 중국인
- 지역 인구 = 주민등록인구 + 등록외국인
- 제주가 지역 인구 100명당 비율 기준 17개 시도 중 1위
